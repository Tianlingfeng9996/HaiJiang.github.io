# 添加学习笔记

1. 将 `_drafts/learning-note-template.md` 复制为 `_notes/short-english-slug.md`。文件名会成为 `/notes/short-english-slug/` 的地址。
2. 填写标题、实际写作日期、语言（`zh`、`en` 或 `ja`）、主题、标签和一句话摘要。
3. 写作期间保留 `published: false`。准备公开时才改成 `published: true`。`_drafts` 本身不发布。
4. 提交并通过网站构建后合并到 `master`；目录自动按日期倒序列出笔记。

正文使用 Markdown，可写代码块、MathJax 公式和图片。图片存放在 `images/notes/`，使用带 `relative_url` 的图片路径以兼容项目站点。

只发布自己的解释、推导和实验；引用时提供课程、教材或论文来源。不要把未获授权的完整课程讲义、作业答案或未公开研究数据随笔记上传。
